## Краткая теория

`ForeignKey` задаёт связь «многие к одному», `ManyToManyField` — «многие ко многим», `OneToOneField` — «один к одному». Параметр `on_delete` определяет поведение зависимой записи при удалении связанного объекта. `related_name` задаёт имя обратной связи. `null` разрешает пустое значение в базе данных, а `blank` — пустое значение в форме.
